How It Works

Three steps. One transaction.

1

Choose Token

Select ETH, USDC.e, tBTC, USDT, or any ERC-20 token on BOB. For ERC-20s, approve the contract first.

2

Add Recipients

Input wallet addresses and amounts — variable amounts per recipient or equal splits for everyone.

3

Send in One Tx

The smart contract batches all transfers. Everyone gets paid in a single transaction on BOB.
